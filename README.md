Este projeto é o Front-End para o MVP da Disciplina **Desenvolvimento Full Stack Básico** 

A aplicação foi construída como uma SPA (Single Page Application) e tem como objetivo demonstrar a integração com quatro endpoints da API QueroVisitar:
- POST — adicionar um novo local de interesse
- DELETE — remover um local existente
- GET (rota 1) — retornar uma única entrada filtrada pelo campo local_nome
- GET (rota 2) — retornar todas as entradas do banco ou apenas aquelas que correspondem ao filtro aplicado pelo campo local_pais
O front-end consome esses endpoints dinamicamente, atualizando a interface sem recarregar a página.
---
## Como executar

Basta fazer o download do projeto e abrir o arquivo index.html no seu browser.
